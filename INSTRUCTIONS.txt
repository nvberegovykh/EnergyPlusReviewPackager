EnergyPlus Review Packager v1.03
================================

Quick start
-----------
1. Put each EnergyPlus report beside its matching model input:
   - eplustbl.htm or eplustbl.html
   - in.idf (recommended for complete daily schedules)
2. Run EnergyPlusReviewPackager_v1.03.exe.
3. Select the Baseline and Proposed HTML reports.
4. The app automatically finds a nearby in.idf when available. You can also
   select a model manually.
5. Click Generate ZIP (PDFs).

Windows launcher requirements
-----------------------------
- EnergyPlusReviewPackager_v1.03.exe is a Windows GUI launcher.
- It requires Python 3.10 or newer on the Windows computer.
- On first run, it installs the required BeautifulSoup and ReportLab packages
  for the current Windows user if they are missing.
- The original v1.02 standalone EXE remains in dist as an archived release.

To produce a fully self-contained Windows executable, run BUILD_v1.03.bat on
a Windows computer. The included PyInstaller spec embeds the application icon.

Schedule profiles
-----------------
- A daily schedule chart is created only from a complete 24-hour profile.
- Two-point HTML summary samples (for example 11 a.m. and 11 p.m.) are never
  stretched or mislabeled as a full daily schedule.
- When in.idf is present, the packager resolves referenced Schedule:Year,
  Schedule:Week:Daily, Schedule:Day:Interval, Schedule:Compact,
  Schedule:Constant, and ScheduleTypeLimits objects.
- Only schedules actually referenced by loads, HVAC, thermostats, controls, or
  water-use objects are charted.
- Temperature schedules are converted to Fahrenheit for imperial reports.
- If complete model data is unavailable, the report says so instead of
  inventing values.

Local AI is intentionally not used to generate or modify schedule values.
Schedule extraction is deterministic because EnergyPlus input objects are the
authoritative source. AI can be added later for explanatory narrative only.

Outputs
-------
- Baseline Reports PDF
- Proposed Reports PDF
- Document Index PDF
- HVAC, envelope, and lighting subset PDFs
- Modeling Notes PDF when notes are supplied
- Final ZIP package containing the generated PDFs

Verification
------------
Run the included regression tests from the source folder:

    python -m unittest -v test_schedule_profiles.py

Verify release files with SHA256SUMS_v1.03.txt:

    Get-FileHash ".\EnergyPlusReviewPackager_v1.03.exe" -Algorithm SHA256

The value should match the EXE entry in SHA256SUMS_v1.03.txt.

Code signing
------------
The release includes the icon and Windows application metadata. A trusted
publisher name still requires signing the final EXE with an OV or EV
code-signing certificate.
